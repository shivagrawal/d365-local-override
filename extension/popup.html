Manual start (first-time setup / fallback)

"Start helper" needs a one-time native messaging registration. Run once from the repo root, using the ID shown on this extension's card at chrome://extensions:

install-native-host.cmd <extension-id>

Or skip the extension entirely and start the helper from a terminal:

pcf-local-override launch --bundle "C:\\path\\to\\bundle-folder"

How to run — step by step
  1. Install helper

    Run npm install -g .

  2. Start PCF watcher

    Run npm run start:watch

  3. Launch development browser

    Run pcf-local-override launch --bundle "C:\\path\\to\\bundle-folder"

  4. Open Dynamics

    Use the development Chrome window.

  5. Configure popup

    Select the Dynamics tab and local bundle, scan and select the resource.

  6. Enable override

    Turn on Enable override.
