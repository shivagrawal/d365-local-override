How to run — step by step
  1. One-time helper setup

    Run install-native-host.cmd <extension-id> once from this repo (ID is on this extension's card at chrome://extensions). After this, "Start helper" needs no terminal.

  2. Open Dynamics, click this extension, click "Start helper"
  3. Add an override

    Click "+ Add override", browse to your file, scan for the matching Dynamics resource, then click "Add this override". Repeat to override more than one file at once.

  4. Build watch

    Detected automatically. Click "Start build watch" once, or check "Start automatically with helper" so it's one click going forward.
