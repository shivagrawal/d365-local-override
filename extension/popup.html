How to run — step by step
  1. Keep your PCF project building

    Run npm run start:watch in your control's own project folder, in its own terminal — same as always. This tool serves whatever is currently on disk; it doesn't build your control.

  2. One-time helper setup

    Run install-native-host.cmd <extension-id> once from this repo (ID is on this extension's card at chrome://extensions). After this, "Start helper" below needs no terminal.

  3. Open Dynamics, click this extension, click "Start helper"
  4. Detect and enable

    Browse to your control/solution folder, pick the exact bundle if more than one was found, scan for the matching Dynamics resource, then turn on Enable override.
